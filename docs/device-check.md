# Phone check

Run this on a real iPhone (and an Android phone if a friend has one) using the Vercel URL. The microphone only works over https, so a laptop's local address won't work on a phone. Note the phone model, iOS version and browser in your pull request.

1. Open the site in Safari. Tap Share → Add to Home Screen, then open it from the icon. Check the icon, the status bar area and the record button above the home indicator.
2. Tap the record button. Start Live Captions stays disabled until "Everyone agrees" is on. Deny the microphone prompt and check the message explains how to allow it. Allow it in Safari's website settings and start again.
3. Speak a few sentences. Captions should appear within about 10 seconds, with typing dots while a clip is being transcribed. Check the Listening capsule, the timer and the waveform move.
4. Switch to another app, then come back. The screen must show "Microphone Off" and a red message. Tap the record button to resume, speak, stop, then Save.
5. Check the screen didn't turn off while listening for more than a minute.
6. With "Make AI notes" on, confirm notes appear with transcript quotes. In Ask, try a question the transcript answers and one it doesn't.
7. Settings → Caption Style: try each style and the Custom size slider. The preview and the live screen must match. Classic and High Contrast make the live screen dark.

## Accessibility on the phone

8. **Larger Text:** Settings → Accessibility → Display & Text Size → Larger Text, drag to the largest. Reopen the site: all text is larger, nothing is cut off, nothing scrolls sideways.
9. **VoiceOver:** turn it on (triple-click the side button if set up). Swipe through each screen. Every button, switch and segment reads a clear name and state. Opening a screen reads its title. While listening, each new caption is read once; the typing dots are not. Stopping reads "Microphone Off".
10. **Increase Contrast and Reduce Transparency:** turn both on. Bars become solid, separators and secondary text darker.
11. **Reduce Motion:** turn it on. Sheets and screens change without sliding; the Listening dot stops pulsing.
12. **Dark mode:** everything stays readable, with green buttons and red only for recording and delete.
13. **Flash When Microphone Stops:** turn it on in Settings, start captions, then lock the phone briefly. On return you see one flash and the red message.

## Data

14. Close Safari completely and reopen the site. The session is still there. Delete it from the Transcript tab and confirm it's gone.
